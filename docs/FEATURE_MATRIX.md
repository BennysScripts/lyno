# Funktions- und Abnahmematrix

Die Matrix beschreibt die lokal implementierte Plattform und verweist auf überprüfbare Nutzerwege. Externe Abnahmen sind getrennt aufgeführt. Aktuelle Testergebnisse stehen in TEST_STATUS.md; keine Produktionsfreigabe.
